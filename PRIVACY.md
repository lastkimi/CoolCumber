# CoolCumber Privacy Policy

Last updated: August 20, 2026

CoolCumber is a local-first macOS utility. System telemetry such as thermal
state, available sensor readings, fan state, memory pressure, storage capacity,
network rates, and process resource usage is processed on the Mac to present the
app's monitoring and diagnostic features.

CoolCumber does not include advertising or third-party analytics. The current
product does not upload system telemetry and does not include an online AI
analysis feature in either release channel.

## Privileged helper

The direct-download edition may install a signed privileged helper after the
user explicitly approves it in macOS System Settings. The helper is used only
for bounded, read-only temperature and fan-speed measurements that are
unavailable to an ordinary app. It does not expose process, file, launchd,
battery, fan-write, or maintenance operations. The Mac App Store edition does
not contain or connect to this helper.

## Storage and retention

Local preferences and compact telemetry history remain on the Mac. Free keeps
up to 24 hours of history; Pro and Beta Preview keep up to 30 days. The history
store applies fixed record and file-size limits and removes older records
locally. A user-initiated Pro export writes a CSV file to a location the user
chooses.

Temperature alerts are optional local notifications. CoolCumber requests
notification permission only after the user explicitly enables alerts, and it
does not send alert data to a server. CoolCumber does not operate an account or
cloud telemetry database for the current product.
